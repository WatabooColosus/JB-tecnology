# Prototipo Fase 1 · Vista local
Abre `index.html` desde este directorio. Contiene navegación móvil funcional, un hero, 3 tarjetas de público y los 19 bloques de landing. Utiliza `../../wordpress/design/jb-tokens.css`.

**No es un tema WordPress, no se publica automáticamente** y no pretende incluir el logo final ni un catálogo real. Su propósito es acordar la dirección visual y probar estructura y responsive antes de llevar los elementos a WoodMart Child y Elementor staging.
